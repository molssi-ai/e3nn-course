#
# The book renders the outputs already stored in each .ipynb (`execute_notebooks: "off"`),

# want to *run* the lessons; use this one only to build the book.

#     uv venv --python 3.13 .venv-docs
#     uv pip install --python .venv-docs/bin/python -r book/requirements-docs.txt
#     make -C book html
